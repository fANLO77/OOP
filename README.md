# 🎯 Объектно-ориентированное программирование на C++

**📅 Тип курса:** Семестровый  
**👩‍🏫 Преподаватель:** Моренкова Ольга Ильинична

---

## 📚 О курсе

Курс посвящен изучению основных принципов объектно-ориентированного программирования на языке C++. 

## 🎯 Цели курса

### 🔥 Основная цель
**Научить применять объектно-ориентированный подход в C++ с использованием современных библиотек и инструментов**

### 📈 Конкретные цели
- **Освоить ООП на практике** - от базовых концепций до создания сложных программных систем
- **Научиться эффективно использовать STL** - контейнеры, алгоритмы, итераторы для решения реальных задач
- **Овладеть работой с файлами и потоками** - обработка данных, сериализация, работа с разными форматами
- **Познакомиться с промышленными библиотеками** - на примере Qt для создания полноценных приложений
- **Развить навыки проектирования архитектуры** - от простых классов до сложных иерархий

### 💡 Практический результат
После курса студенты смогут:
- Проектировать и реализовывать объектно-ориентированные системы на C++
- Эффективно использовать стандартные библиотеки для типовых задач
- Создавать приложения с файловым вводом-выводом и обработкой данных
- Применять контейнерные классы для оптимизации работы с данными
- Использовать современные инструменты (STL, Qt) для ускорения разработки

## 📖 Программа курса

### 🔷 Введение в объектно-ориентированное программирование
- Основные концепции и принципы ООП
- Отличия от процедурного подхода

### 🔷 Стандартные библиотеки C++ и STL  
- Обзор стандартных библиотек языка
- Архитектура Standard Template Library

### 🔷 Работа с файлами и потоками
- Текстовые файлы в потоковом стиле
- Бинарные файлы и операции ввода-вывода

### 🔷 Контейнерные классы STL
- Вектор (Vector), Стек (Stack), Очередь (Queue)
- Список (List) - теория, примеры, практическое применение
- Итераторы и алгоритмы работы с контейнерами

### 🔷 Библиотека Qt для C++
- Обзор возможностей и архитектуры Qt
- Создание кроссплатформенных приложений
- Графический интерфейс и основные компоненты
